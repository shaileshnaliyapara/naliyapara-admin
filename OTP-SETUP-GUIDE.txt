NALIYAPARA NOTIFICATION ADMIN - EMAIL OTP SETUP

1) Upload index.html and logo.png to the same admin panel folder.
2) In Supabase Dashboard -> Authentication -> Email Templates -> Magic Link,
   change the email template so it displays the OTP token:

   <h2>Naliyapara Admin Login OTP</h2>
   <p>Your 6-digit login code is:</p>
   <h1>{{ .Token }}</h1>
   <p>This code expires shortly. Do not share it with anyone.</p>

3) Save the template.
4) The admin email must already exist in Supabase Auth because this app uses
   shouldCreateUser:false.
5) Open the admin panel. Enter the admin email -> OTP મોકલો -> enter the 6-digit
   code -> Login.

The old password field is removed from the login page.
